1. Quick Workflow (Tabs 1 → 3)

Tabs 1 & 2: Calibrate, Track & Predict

  • Open Video & FPS: Click 📹 Open Video. Set FPS to real rate (normal: 30/60; iPhone slow-mo: 120/240).
  • Set Scale First: Click 📏 1. Set Scale, drag across your meter stick, enter meters in 1A, click Apply Scale.
  • Set Origin: Click 🎯 2. Set Origin. Put \(y = 0\) on the floor, \(x = 0\) below launch.
  • Track Ball: Step to first airborne frame. Click ➕ 3. Track Ball and click center 10–15 times (rise, apex, fall). Stop before bounce!
  • Set \(t_{\text{up}}\) (1B): Click Use Peak Frame t.
  • Tab 2 (Predict): Pick shapes + 1-sentence reason → 🔒 Lock Prediction & Go to Tab 3: Build Graphs →.
    Right-to-left shot? Pick Flat negative horizontal line (\(v_x < 0\))!

Tab 3: Build 6 Graphs (3A → 3D)

  • 3A. Position: • \(x(t)\) → Linear (\(x = mt + c\)) • \(y(t)\) → Quadratic (\(At^2+Bt+C\))
  • 3B. Tangent Slopes & Velocity: Click Ascent, Apex, Descent and press ➕ Plot This Tangent Slope 3+ times.
    • \(v_y(t)\) → Linear  |  \(v_x(t)\) → Constant (\(v_x = m\))
  • 3C. Acceleration: • \(a_x(t)\) → Constant Zero (\(a_x = 0\)) • \(a_y(t)\) → Constant (\(a_y = \text{slope of } v_y\))
  • 3D. Notes: Write 1–2 sentences comparing your prediction and explaining how slopes give \(v\) and \(a\). (Extended: check 📐 Shade Signed \(v_y\)–\(t\) Areas)
2. Best-Fit Equation Decoder Ring (Pinned at Top of Tab 4)

Horizontal Line \(x(t)\)

\(x(t) = m\,t + c\)
  • Initial position: \(x_0 = c\) (m)
  • Horizontal velocity: \(v_{0x} = m\) (m/s) — constant!
  • Horizontal accel.: \(a_x = 0\text{ m/s}^2\)
  • Sign rule: Right \(\Rightarrow m > 0\). Left \(\Rightarrow m < 0\) (keep minus sign!).

Vertical Curve \(y(t)\)

\(y(t) = A\,t^2 + B\,t + C\)
  • Initial height: \(y_0 = C\) (m)
  • Initial vertical velocity: \(v_{0y} = B\) (m/s)
  • Vertical accel.: \(a_y = \mathbf{2A}\) (m/s\(^2\)) — Multiply \(A\) by 2! Expect near \(-9.8\text{ m/s}^2\).

Key Lab Symbols

\(t_{\text{hang}}\): First to last tracked point. Do NOT use \(2t_{\text{up}}\) unless start/end heights match!
\(t_{\text{up}}\): Time from \(t = 0\) to highest tracked frame in 1B.
\(y_{\text{final}}\): Height \(y\) of your last tracked frame (usually not \(0\)).

3. Tab 4: Kinematics Calculations 1–7 (Standard Version)
% Difference: \(\text{\% diff} = |\text{Calc} - \text{Meas}| \div |\text{Meas (or Ref)}| \times 100\%\) Rule: Show equation + numbers + units in every Work box!
Calculation Formula / How to Calculate (Fit Values) Measure / Compare With
1. Fit Values Read from Tab 3 fits: \(x_0 = c\), \(v_{0x} = m\), \(a_x = 0\), \(y_0 = C\), \(v_{0y} = B\), \(a_y = \mathbf{2A}\). % diff of \(a_y\) vs. \(-9.8\text{ m/s}^2\). Compare \(a_x\) with \(0\) (no % diff).
2. Hang Time \(t_{\text{hang}}\) Solve \(y_{\text{final}} = y_0 + v_{0y}t + \tfrac{1}{2}a_y t^2\) → \((\tfrac{1}{2}a_y)t^2 + v_{0y}t + (y_0 - y_{\text{final}}) = 0\):
\(t = (-v_{0y} \pm \sqrt{v_{0y}^2 - 4(\tfrac{1}{2}a_y)(y_0 - y_{\text{final}})}) / a_y\). Keep larger positive root.		 Measured: \(t_{\text{last}} - t_{\text{first}}\) (shown as \(t_{\text{hang}}\) in Tab 4 bar).
3. Range \(\Delta x\) \(\Delta x = v_{0x}\,t_{\text{calc}}\) (since \(a_x = 0\); plug in calculated hang time from #2). Measured: \(x_{\text{final}} - x_{\text{initial}}\) (from Tab 1C or Tab 4 bar).
4. Max Height \(y_{\max}\) At peak, \(v_y = 0 \Rightarrow \Delta y_{\text{up}} = v_{0y}^2 / (2|a_y|)\). Then \(y_{\max} = y_0 + \Delta y_{\text{up}}\). Measured: Highest \(y\) in Tab 1C table (peak \(y_{\max}\) in bar).
5. Launch Speed \(v_0\) \(v_0 = \sqrt{v_{0x}^2 + v_{0y}^2}\) Always positive (m/s).
6. Launch Angle \(\theta\) Use calculator DEG mode: \(\theta = \tan^{-1}(|v_{0y}| / |v_{0x}|)\) above horizontal. High lob > \(45^\circ\); flat shot < \(45^\circ\).
7. Gravity Check \(g_{\text{meas}}\) From measured rise \(\Delta y_{\text{up}} = y_{\max,\text{meas}} - y_0\) and video \(t_{\text{up}}\):
\(g_{\text{meas}} = 2(y_{\max,\text{meas}} - y_0) / t_{\text{up}}^2\)		 % diff vs. fitted \(|a_y|\) AND % diff vs. \(9.8\text{ m/s}^2\). Write 1 sentence if both agree.
Extended Mode (5a–5f & 5A): 5a–5b take 2-point slopes; 5c uses \(v_{0y,\text{pred}} = 9.8\,t_{\text{up}}\); 5d–5e use \(a_{y,\text{ref}} = -9.8\text{ m/s}^2\); 5A adds signed triangle areas at \(t_{\text{zero}}\) so \(C + \Delta y_{\text{area}} \approx y_{\text{fit}}(t_{\text{hang}})\).
4. Tab 5 Reasoning Prompts & Troubleshooting FAQ

Tab 5B Conceptual Prompts

  • At rest at apex (\(v_y = 0\))? No! \(v_y = 0\) for an instant only, while \(v_x \neq 0\) keeps moving horizontally in 2D.
  • Why is \(a_y < 0\) on both sides? Gravity always pulls down (\(-y\)): it slows the ball going up (\(v_y > 0\)) and speeds it up coming down (\(v_y < 0\)).
  • Limitation + Direction: State 1 error (frame spacing at peak, blur, or scale distance) AND say if your number became too high or too low.
  • Gravity Conclusion: State your \(a_y\) % diff from \(-9.8\text{ m/s}^2\); if >15% off, explain the setup cause.

FAQ: Fixes Before Asking Your Teacher

Why is "✓ Check My Numbers" greyed out? Type equations/work into at least one Work box in Tab 4 first to unlock checking.
Red Banner: "Your FPS setting may be 2×/4× off"? Slow-mo clips export at 30, 60, 120, or 240 fps. Update FPS in Tab 1 until \(a_y \approx -9.8\text{ m/s}^2\).
Points shifted after reloading video + .json? Slide 🎯 Align Overlay to Video (X, Y, Scale) in Tab 1—your data stays unchanged!
How to save & turn in (Tab 6)? Click 💾 Save (.json) for backup, enter Name & Teacher, click 🖨️ Print / Save Report as PDF, choose Save as PDF (do not print paper).
