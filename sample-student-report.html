3. Step-by-Step Algebraic Kinematics Derivations (No Shortcut Formulas)
1. Resultant Launch Speed ($v_0$) & Launch Angle ($\theta$)
• Given: $v_{0x} = 2.629\text{ m/s}$, $v_{0y} = 4.944\text{ m/s}$
• $v_0 = \sqrt{v_{0x}^2 + v_{0y}^2} = \sqrt{(2.629)^2 + (4.944)^2} = \sqrt{31.355} = \mathbf{5.600\text{ m/s}}$
• $\theta = \tan^{-1}\!\left(\frac{v_{0y}}{v_{0x}}\right) = \tan^{-1}\!\left(\frac{4.944}{2.629}\right) = \mathbf{62.00^\circ}$
• Check: $v_0\cos(62^\circ) = 2.629\text{ m/s}$, $v_0\sin(62^\circ) = 4.944\text{ m/s}$ ✓
2. Maximum Apex Height ($y_{\text{max}}$)
• Fundamental Eq: $v_{fy}^2 = v_{0y}^2 + 2a_y(y_{\text{max}} - y_0)$ (at apex, $v_{fy} = 0$)
• $0^2 = (4.944\text{ m/s})^2 + 2(-9.780\text{ m/s}^2)(y_{\text{max}} - 1.200\text{ m})$
• $19.560(y_{\text{max}} - 1.200) = 24.443 \implies y_{\text{max}} - 1.200 = 1.250\text{ m}$
• $y_{\text{max}} = 1.200\text{ m} + 1.250\text{ m} = \mathbf{2.450\text{ m}}$ (Measured: $2.450\text{ m}$)
3. Flight Hang Time ($t_{\text{hang}}$) via Quadratic Formula
• Fundamental Eq: $y(t) = y_0 + v_{0y}t + \frac{1}{2}a_y t^2$ ($y_{\text{final}} = 1.255\text{ m}$)
• $1.255 = 1.200 + 4.944t - 4.890t^2 \implies -4.890t^2 + 4.944t - 0.055 = 0$
• $t = \frac{-4.944 - \sqrt{(4.944)^2 - 4(-4.890)(-0.055)}}{2(-4.890)} = \frac{-4.944 - 4.834}{-9.780} = \mathbf{1.000\text{ s}}$
4. Horizontal Range ($\Delta x$)
• Fundamental Eq: $\Delta x = v_{0x}t_{\text{hang}} + \frac{1}{2}a_x t_{\text{hang}}^2$ ($a_x = 0\text{ m/s}^2$)
• $\Delta x = (2.629\text{ m/s})(1.000\text{ s}) + 0 = \mathbf{2.629\text{ m}}$
• Measured from Video: $x_{\text{final}} - x_0 = 2.629\text{ m} - 0.000\text{ m} = \mathbf{2.629\text{ m}}$
